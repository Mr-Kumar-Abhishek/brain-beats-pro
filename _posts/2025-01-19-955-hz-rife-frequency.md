### 1. Microbiological & Pathological Profile

- **Pathophysiology of Recurrent Aphthous Stomatitis (RAS) & Mucosal Inflammation**: Recurrent aphthous stomatitis (canker sores) is a common chronic inflammatory ulcerative condition affecting non-keratinized oral mucosa (such as buccal, labial, and ventral tongue surfaces). Rather than a direct primary bacterial or viral infection, RAS is driven by localized dysregulation of cell-mediated immunity. An exaggerated infiltration of cytotoxic CD8+ T-lymphocytes and pro-inflammatory cytokine hyper-secretion (notably tumor necrosis factor-alpha [TNF-$\alpha$], interleukin-1$\beta$, and interleukin-6) triggers focal epithelial keratinocyte apoptosis, mucosal necrosis, and painful ulcer formation covered by a fibrinous pseudo-membrane surrounded by an erythematous border.
- **Therapeutic Regimens & openFDA Clearances**: Evidence-based clinical management of recurrent aphthous stomatitis focuses on controlling localized pain, suppressing cell-mediated mucosal inflammation, and accelerating re-epithelialization:
  - *Topical Glucocorticoids*: Triamcinolone acetonide dental paste (Kenalog in Orabase, FDA NDA 012002 / NDA 014901), formulated in an adhesive emollient vehicle that adheres tenaciously to oral mucosal ulcers, delivering concentrated local anti-inflammatory and immunosuppressive action.
  - *Anti-Inflammatory & Anti-Allergic Agents*: Amlexanox 5% oral paste (Aphthasol, FDA NDA 020516), which inhibits the localized synthesis and release of inflammatory leukotrienes and histamine from mast cells, significantly accelerating ulcer resolution.
  - *Topical Anesthetics*: Viscous Lidocaine 2% solution (FDA NDA 008816) for temporary mucosal numbing during mastication and speech. Acoustic sound vibrations cannot suppress cytotoxic T-lymphocytes, block inflammatory cytokines, or provide an emollient mucosal barrier.
- **Audible Mid-Frequency Sound Physics**: At 955 Hz ($T \approx 0.001047\text{ s}$), acoustic waves travel at $\lambda \approx 1.613\text{ m}$ through biological soft tissue and $\lambda \approx 0.359\text{ m}$ in atmospheric air. This frequency offers a coherent acoustic tone utilized in psychoacoustic relaxation, auditory sensory training, and somatic resonance modeling.

### 5. Web Audio API Master Synthesizer

```javascript
/**
 * Rife955Synthesizer - Web Audio API Synthesis Engine for 955 Hz
 * Synthesizes a clean 955 Hz audible acoustic pure tone with anti-click ramps.
 */
class Rife955Synthesizer {
    constructor(audioCtx = null) {
        this.ctx = audioCtx || new (window.AudioContext || window.webkitAudioContext)();
        this.oscillator = null;
        this.gainNode = null;
        this.isPlaying = false;
    }

    start(volume = 0.5) {
        if (this.isPlaying) return;
        if (this.ctx.state === 'suspended') {
            this.ctx.resume();
        }

        const now = this.ctx.currentTime;
        this.oscillator = this.ctx.createOscillator();
        this.gainNode = this.ctx.createGain();

        this.oscillator.type = 'sine';
        this.oscillator.frequency.setValueAtTime(955, now);

        // Smooth exponential attack ramp to prevent acoustic clicks
        this.gainNode.gain.setValueAtTime(0.001, now);
        this.gainNode.gain.exponentialRampToValueAtTime(Math.max(0.001, volume), now + 0.05);

        this.oscillator.connect(this.gainNode);
        this.gainNode.connect(this.ctx.destination);

        this.oscillator.start(now);
        this.isPlaying = true;
    }

    stop() {
        if (!this.isPlaying) return;
        const now = this.ctx.currentTime;
        this.gainNode.gain.setValueAtTime(this.gainNode.gain.value, now);
        this.gainNode.gain.exponentialRampToValueAtTime(0.0001, now + 0.05);

        setTimeout(() => {
            if (this.oscillator) {
                this.oscillator.stop();
                this.oscillator.disconnect();
            }
            this.isPlaying = false;
        }, 60);
    }
}
```
